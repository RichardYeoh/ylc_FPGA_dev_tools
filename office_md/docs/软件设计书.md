| 版本 | 1.0.0 |
| 编写日期 | 2026-10-21 |
| 运行平台 | Windows 10 / 11 x64 |
| 运行形态 | 绿色免安装，整目录拷贝即可迁移 |

---

## 1 概述

### 1.1 编写目的

本文档描述 office_md 的总体架构、模块划分、关键算法、转换规则、异常策略与打包迁移方案，供后续维护、二次开发与交付验收使用。

### 1.2 术语

| 术语 | 说明 |
| --- | --- |
| OOXML | Office Open XML，.docx/.xlsx/.pptx 的底层格式（ZIP + XML） |
| 老格式 | .doc / .xls / .ppt，二进制 OLE 复合文档 |
| COM | Microsoft Office 提供的自动化接口，通过 pywin32 调用 |
| onedir | PyInstaller 的一种输出形态：exe + 依赖目录 |

### 1.3 需求摘要

1. 支持 Word / Excel / PowerPoint 转 Markdown；
2. Windows 下双击即可运行（一键）；
3. 运行期完全离线，不依赖网络与在线服务；
4. 开发机调通后，整目录拷贝即可在无网络的内网机运行；
5. 复用现成开源库，依赖安装包随项目保存；
6. 交付软件设计书与使用说明书。

## 3 技术选型

### 3.1 备选方案对比

| 方案 | 覆盖格式 | 体积 | 目标机要求 | 结论 |
| --- | --- | --- | --- | --- |
| 纯 Python 解析 OOXML | docx/xlsx/pptx（老格式需 COM） | 约 58 MB | 无（老格式需 Office） | **采用** |
| 内嵌 pandoc | 仅 docx 等，不支持 xlsx/pptx | 约 150 MB | 无 | 放弃，覆盖不全 |
| LibreOffice 便携版 | 全格式 | 约 350–500 MB | 无 | 放弃，体积大、启动慢 |
| 直接调用 Office COM 另存 | 全格式 | 极小 | 需 Office | 仅用于老格式兜底 |

### 3.2 选定方案

**主干：纯 Python 解析 OOXML + 自研 Markdown 渲染；老格式：Office COM 另存后复用同一套主干。**

理由：
1. 主干不依赖外部进程，转换速度最快（样例 3 个文件 < 0.5 秒）；
2. 输出可控，可以针对工程类文档（多表格、多图片、多级标题）做专门优化；
3. 老格式只在必要时启动 Office，平均耗时 3–6 秒/文件，可接受；
4. 发行包约 58 MB，远小于 LibreOffice 方案。

### 3.3 依赖清单

| 库 | 版本 | 用途 |
| --- | --- | --- |
| python-docx | 1.2.0 | 读取 .docx 的 OOXML 结构 |
| openpyxl | 3.1.5 | 读取 .xlsx（含缓存值与合并区域） |
| python-pptx | 1.0.2 | 读取 .pptx 的幻灯片、形状、图表 |
| xlrd | 2.0.2 | 纯 Python 读取老格式 .xls |

| pywin32 | 312 | 调用 Office COM 转换老格式 |

## 5 详细设计

### 5.1 调度核心（core.py）

| 函数 | 职责 |
| --- | --- |
| `app_root()` | 返回程序根目录；打包后为 exe 所在目录，源码运行为项目根 |
| `collect_inputs()` | 把文件/目录展开为待转换列表，去重、按扩展名过滤、跳过输出目录 |
| `target_path()` | 计算输出 md 路径（同目录或指定目录） |
| `_dispatch()` | 按扩展名分派到具体转换器，并注入 `title_name` |
| `convert_one()` | 单文件转换，捕获全部异常并收敛为 `Result` |
| `convert_many()` | 批量转换，支持进度回调、取消、目录结构保持 |
| `format_report()` | 生成可读汇总报告 |

**错误隔离**：`convert_one` 内部捕获 `OfficeConversionError`、`PermissionError` 与通用异常，任何单文件失败只影响该条 `Result`。

**目录结构保持**：输入是目录时，输出按"相对输入根的路径"在输出目录下重建，避免同名文件互相覆盖。

### 5.2 Word 转换（converters/docx_c.py）

**主路径**：用 python-docx 直接遍历文档 XML 流。

1. `_iter_blocks()` 按 XML 顺序产出 `w:p`（段落）、`w:tbl`（表格），并展开内容控件 `w:sdt`；
2. 标题识别优先级：`w:outlineLvl`（大纲级别）> 样式名 `Heading N`/`标题 N` > 样式 ID `HeadingN`，并沿 `base_style` 链回溯；
3. 列表识别：样式名含 `List Bullet`/`项目符号` → 无序；含 `List Number`/`编号列表` → 有序（按层级自增序号）；存在 `w:numPr` 但样式未知时按无序处理；
4. 行内格式：遍历 `w:r` 的 `w:rPr`，还原粗体、斜体、删除线、等宽字体（行内代码）；
5. 超链接：`w:hyperlink` 的 `r:id` 查关系表得到 URL，输出 `[文本](URL)`；
6. 图片：DrawingML 的 `a:blip/@r:embed` 与 VML 的 `v:imagedata/@r:id` 查关系表取二进制，落盘后插入 `![](相对路径)`；
7. 公式：`m:oMath` 提取 `m:t` 纯文本，用行内代码包裹，**不做 LaTeX 转换**（避免生成错误公式）；
8. 表格：按行列遍历，合并单元格通过"同一 `w:tc` 元素只取一次"去重，其余留空；嵌套表格展开到主表之后；
9. 列表连续性：相邻同类型列表项之间只保留单换行，否则 Markdown 会拆成多个列表。

**兜底路径**：主路径抛异常时，用 mammoth 把 docx 转 HTML（图片通过 `convert_image` 回调落盘），再经 markdownify 转 md。

**标题处理**：正文已存在一级标题时不再插入文档属性标题，避免重复；正文无一级标题时才用 `core_properties.title` 补一个 `#`。

### 5.3 Excel 转换（converters/xlsx_c.py）

- 用 `openpyxl.load_workbook(data_only=True)` 读取**公式缓存值**；
- 若整簿无任何缓存值，退回 `data_only=False` 读取公式原文并告警；
- 若只是**部分**公式无缓存值，统计数量并告警（提示用 Excel 打开另存一次）；
- 合并单元格：只保留左上角值，其余留空，保证行列表格对齐；
- 日期按 `YYYY-MM-DD`（含时间则带 `HH:MM:SS`）输出；浮点整数去 `.0`；
- 每个工作表输出 `## 工作表名` + 一张 md 表格；隐藏工作表默认跳过（可开关）；
- 全空行列自动裁剪，避免大量空表格行。

老格式 `.xls` 走 `xlrd`：
- `formatting_info=True` 时还原合并区域（`sheet.merged_cells`）；
- `sheet.visibility` 非 0 视为隐藏表；
- xlrd 失败（加密、损坏等）时自动经 Office 另存为 xlsx 后复用 xlsx 路径。

### 5.4 PowerPoint 转换（converters/pptx_c.py）

- 每页输出 `## <序号>. <标题>`，无标题时用 `## <序号>. 第N页`；
- 形状分派：组合形状递归、表格、图表、图片、文本框、线条（忽略）；
- 文本框：`level > 0` 的段落转缩进列表；
- 图表：从 `plot.categories` 与各 `series.values` 还原成 md 表格（首列类别，其余列系列）；
- 图片：`shape.image.blob` 落盘，引用相对路径；
- 演讲者备注：输出为引用块，可用选项关闭；
- 单个形状解析失败只记录警告，不影响整页。

### 5.5 老格式兼容（office_com.py）

| 函数 | 说明 |
| --- | --- |
| `detect_office()` | 读注册表判断 Word/Excel/PowerPoint 是否存在，并检查 pywin32 |
| `doc_to_docx()` | Word `SaveAs2(FileFormat=16)` 另存 docx |
| `ppt_to_pptx()` | PowerPoint `SaveAs(FileFormat=24)` 另存 pptx |
| `xls_to_xlsx()` | Excel `SaveAs(FileFormat=51)` 另存 xlsx（xlrd 失败时兜底） |
| `TempWorkspace` | 转换期临时目录，`with` 退出时删除 |

**安全约束**：
1. 用 `DispatchEx` 起独立实例，不干扰用户正在编辑的文档；
2. 源文件一律 `ReadOnly=True` 打开；
3. `finally` 中依次 Close / Quit / `CoUninitialize`，保证不残留后台进程；
4. 未检测到 Office 时抛出可读错误，提示改用另存为新格式。

### 5.6 Markdown 生成（mdutil.py）

| 函数/类 | 说明 |
| --- | --- |
| `to_text()` | 值转字符串，浮点整数去 `.0` |
| `clean_cell()` | 转义表格分隔符 `|`，换行折叠为 `<br>` |
| `render_table()` | 生成 GFM 表格，自动补列、丢空列、强制表头行 |
| `squash_blank_lines()` | 连续空行压缩，避免 md 中出现大片空白 |
| `ImageStore` | 图片按 SHA1 去重落盘到 `<md名>_files/`，返回相对路径 |

图片目录与 md 文件同级，保证「拷走一个 md + 一个目录」即可完整查看。

### 5.7 图形界面（gui.py）

- 基于 tkinter（Python 内置，零第三方依赖，便于打包）；
- 启动时设置 DPI 感知，避免高分屏模糊；
- 布局三块：待转换文件列表 / 输出与选项 / 运行日志；
- 转换在后台线程执行，通过 `queue.Queue` 回传进度，主线程 `after()` 轮询刷新，避免界面卡死；
- 启动时自动检测 Office 组件并提示，便于用户提前判断老格式是否可用。

### 5.8 命令行（cli.py）

```
office2md [文件或目录 ...] [-o 输出目录] [--no-recursive] [--no-notes]
          [--hidden-sheets] [--no-overwrite] [--debug] [-v]
```

- 无参数：窗口版启动 GUI，控制台版打印帮助；
- 退出码：0 全部成功，1 部分失败，2 参数或路径错误；
- 启动时把控制台代码页切到 65001，避免中文乱码。

### 5.9 日志（logging_util.py）

- 日志文件 `logs/office2md_YYYYMMDD.log`，超过 4 MB 自动重建；
- `safe_print()` 兼容 `--windowed` 打包后 `sys.stdout is None` 的情况，任何输出都不会导致崩溃；
- 日志写入失败静默处理，绝不影响转换主流程。

## 6 转换规则映射

### 6.1 Word → Markdown

| Word 元素 | Markdown 输出 |
| --- | --- |
| 标题 1–9（大纲级别/样式） | `#` ~ `######` |
| 正文段落 | 普通段落，段落间空行 |
| 粗体 / 斜体 / 删除线 / 等宽 | `**x**` / `*x*` / `~~x~~` / `` `x` `` |
| 无序 / 有序列表 | `-` / `1.`（按层级缩进 2 空格） |
| 表格 | GFM 表格，首行作表头，合并单元格留空 |
| 内嵌图片 | `![](<md名>_files/imageNNN.ext)` |
| 超链接 | `[文本](URL)` |
| 公式 | 行内代码包裹的纯文本（不转 LaTeX） |
| 引用样式段落 | `> ` 引用块 |
| 页眉页脚 / 脚注 / 文本框 | 不输出（已知限制） |

### 6.2 Excel → Markdown

| Excel 元素 | Markdown 输出 |
| --- | --- |
| 工作表 | `## 工作表名` + 表格 |
| 单元格 | 表格单元格，`|` 转义，换行转 `<br>` |
| 合并单元格 | 左上角有值，其余留空 |
| 公式 | 取缓存值；无缓存时输出公式原文并告警 |
| 日期 | `YYYY-MM-DD` / `YYYY-MM-DD HH:MM:SS` |
| 隐藏工作表 | 默认跳过 |

### 6.3 PowerPoint → Markdown

| PPT 元素 | Markdown 输出 |
| --- | --- |
| 幻灯片 | `## 序号. 标题` |
| 标题占位符 | 作为该页标题 |
| 文本框 | 段落；`level>0` 转缩进列表 |
| 图片 | `![](_files/imageNNN.ext)` |
| 表格 | GFM 表格 |
| 图表 | 由图例/类别/数值还原的表格 |
| 演讲者备注 | `> **备注**` 引用块 |
| 组合形状 | 递归展开 |

## 7 异常与降级策略

| 场景 | 处理 |
| --- | --- |
| .docx 主解析失败 | 自动改用 mammoth → markdownify，并记录警告 |
| .xls 的 xlrd 失败 | 自动经 Office 转 xlsx 后复用 xlsx 路径 |
| 未安装 Office 却要转老格式 | 抛出明确错误：提示安装 Office 或另存为新格式 |
| 文件被占用 / 无写权限 | 捕获 `PermissionError`，该文件标记失败，其余继续 |
| 目标 md 已存在且关闭覆盖 | 跳过并提示 |
| 整簿无公式缓存值 | 输出公式原文并告警 |
| 单个 PPT 形状解析失败 | 记录警告，其余形状正常输出 |
| 输出为空 | 判定失败并提示"文档可能没有可提取文字" |
| 界面异常 | 捕获后提示改用命令行方式 |

## 8 打包与迁移设计

### 8.1 两种运行形态

| 形态 | 入口 | 适用场景 |
| --- | --- | --- |
| 打包版（主推） | `office2md.exe`（双击启动 GUI） | 目标内网机，无需 Python |
| 控制台版 | `office2md-cli.exe` / `拖放文件转换.bat` | 批处理、拖放、脚本化 |
| 源码版 | `python app.py` | 开发机调试、二次开发 |

三个入口共用同一份 `src/office2md` 代码。

### 8.2 打包流程

```
build\build_exe.bat
  ├─ 1. pip install --no-index --find-links=vendor\wheels -r requirements.txt -r requirements-build.txt
  ├─ 2. pyinstaller --distpath dist --workpath build\work build\office2md.spec
  └─ 3. python tools\make_release.py   → dist\office2md-1.0.0-win64\ + .zip
```

spec 关键点：
- `console=False`（GUI）与 `console=True`（CLI）两个 EXE，共享同一个 `_internal`；
- `hiddenimports` 显式声明 `win32com.client.dynamic`、`pythoncom`、`lxml.etree` 等动态导入模块；
- `excludes` 排除 pandas/numpy/matplotlib/PyQt 等未使用的大库，控制体积（当前约 58 MB）。

### 8.3 迁移方式

1. 把 `dist\office2md-1.0.0-win64\` 整个目录拷贝到目标机任意路径（U 盘、共享盘均可）；
2. 双击 `启动转换工具.bat` 或 `office2md.exe`；
3. 无需安装、无需管理员权限、无需配置环境变量。

约束：路径建议不含特殊字符；程序目录需可写（日志、临时文件写在程序目录内）。

### 8.4 目标机要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 x64 |
| 运行库 | 无需额外安装（VC 运行库已随包/系统自带） |
| Python | 不需要 |
| Office | 仅在转换 .doc/.ppt（以及 xlrd 失败时的 .xls）时需要 |
| 网络 | 不需要 |

## 10 已知限制

| 编号 | 限制 | 影响 | 可能的改进 |
| --- | --- | --- | --- |
| L1 | 公式仅提取纯文本，不转 LaTeX | 复杂公式不可直接渲染 | 引入 OMML→LaTeX 转换器 |
| L2 | 不输出页眉页脚、脚注、批注、文本框 | 少量信息缺失 | 增加可选附录章节 |
| L3 | Word 合并单元格在 md 中表现为留空 | 视觉上不显示单元格跨度 | md 无法表达合并，属格式限制 |
| L4 | Excel 图表、条件格式、图片不导出 | 仅导出单元格数据 | 增加图片提取 |
| L5 | PPT SmartArt、动画、母版装饰不输出 | 图形信息缺失 | 解析 diagram XML |
| L6 | 老格式依赖 Office | 目标机必须装 Office | 已确认目标环境具备 |
| L7 | 单个 md 文件可能较大（宽表多行） | 阅读体验下降 | 增加按工作表拆分选项 |
