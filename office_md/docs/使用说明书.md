# office_md 使用说明书

版本 1.0.0 ｜ 适用平台：Windows 10 / 11 x64 ｜ 完全离线

---

## 1 这个工具能做什么

把 Word、Excel、PowerPoint 文档转换成 Markdown（`.md`）文本文件，便于放进 Git、知识库、静态站点或 AI 工具里阅读和检索。

| 输入 | 输出 |
| --- | --- |
| `.docx` `.docm` `.doc` | 同名 `.md` + `<md名>_files/` 图片目录 |
| `.xlsx` `.xlsm` `.xls` | 同名 `.md`（每个工作表一个章节） |
| `.pptx` `.pptm` `.ppt` | 同名 `.md`（每张幻灯片一个章节） |

三个特点：

1. **不用装任何东西**：发行包自带全部运行环境，双击就能用；
2. **不用联网**：所有转换在本机完成，不访问任何网络；
3. **可以随便搬**：整个文件夹拷到别的 Windows 电脑上照样能跑。

## 2 运行环境要求

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | Windows 10 / 11，64 位 | 不支持 32 位系统 |
| 磁盘空间 | 约 100 MB | 程序约 58 MB，另需预留输出空间 |
| 管理员权限 | **不需要** | 直接解压/拷贝即可运行 |
| Python | **不需要** | 运行时已打包进程序 |
| 网络 | **不需要** | 运行期零网络访问 |
| Microsoft Office | **仅老格式需要** | 转 `.doc` / `.ppt` 时必须装 Office；`.docx` / `.xlsx` / `.pptx` 不需要 |

> 说明：本内网环境的目标机均已安装 Office，因此 `.doc` / `.ppt` 可以直接转换。

## 3 部署（第一次拿到程序时做一次）

### 3.1 从压缩包部署

1. 把 `office2md-1.0.0.zip` 拷贝到目标机；
2. 右键 → 「全部解压缩」，**解压到本地磁盘**（例如 `D:\tools\`）；
   - 不建议直接在压缩包预览窗口里双击运行，也不建议放在网络共享路径上运行（速度慢）；
3. 解压后得到 `office2md-1.0.0\` 目录，里面是「两个版本 + 一份选择说明」：

```
office2md-1.0.0\
├─ 选择说明.txt                   两个版本怎么选（先看这个）
├─ office2md-1.0.0-win64\         ← 日常使用选这个（exe 版）
│  ├─ office2md.exe               图形界面主程序
│  ├─ office2md-cli.exe           控制台版
│  ├─ _internal\                  运行库（必须与 exe 同级，勿删勿改）
│  ├─ 启动转换工具.bat             一键启动图形界面
│  ├─ 拖放文件转换.bat             把文件拖到图标上直接转换
│  ├─ 使用说明书.md / 软件设计书.md / 迁移部署说明.md
│  ├─ 版本信息.txt
│  └─ samples\                    示例文件
└─ office2md-1.0.0-src-portable\  ← 要改代码选这个（源码便携版）
   ├─ app.py
   ├─ src\office2md\              转换逻辑源码
   ├─ runtime\                    自带 Python 3.13 运行时
   └─ ...（bat、文档、samples 同上）
```

4. 进入 `office2md-1.0.0-win64\`，双击 `启动转换工具.bat`（或直接双击 `office2md.exe`）即可使用。

### 3.2 从 U 盘 / 共享盘拷贝部署

直接把整个 `office2md-1.0.0-win64` 文件夹复制到目标机本地磁盘即可，无需安装、无需注册、无需配置环境变量。

### 3.3 部署后自检（建议做一次）

1. 双击启动程序，窗口能正常打开；
2. 日志区显示 `Office 检测：Word=True Excel=True PowerPoint=True pywin32=True`；
3. 添加 `samples` 文件夹并转换，能看到 3 个文件「成功」。

以上三步都通过，说明部署完整。

## 4 用法一：图形界面（推荐）

### 4.1 操作步骤

1. 双击 `启动转换工具.bat`；
2. 点「添加文件…」选择若干 Office 文件，或点「添加文件夹…」选择整个目录（会自动递归查找子目录里的 Office 文件）；
3. 选择输出位置：
   - 勾选「输出到源文件所在目录」（默认）→ md 与源文件放在一起；
   - 取消勾选后点「浏览…」→ 统一输出到指定目录；
4. 按需勾选选项：
   | 选项 | 说明 |
   | --- | --- |
   | 包含 PPT 备注 | 把演讲者备注以引用块形式写入 md，默认开启 |
   | 包含隐藏工作表 | 是否转换 Excel 中被隐藏的工作表，默认关闭 |
   | 覆盖已存在的 md | 关闭后遇到同名 md 会跳过，默认开启 |
5. 点「开始转换」，进度条和日志区会实时显示每个文件的处理结果；
6. 完成后日志区会给出汇总：`总计 N 个文件：成功 X，失败 Y`；
7. 点「打开输出目录」直接查看结果。

### 4.2 界面区域说明

| 区域 | 作用 |
| --- | --- |
| ① 待转换文件 | 添加/移除文件，支持多选；文件夹会被展开成文件列表 |
| ② 输出与选项 | 输出位置与三个转换开关 |
| ③ 运行日志 | 进度、每个文件的成功/失败原因、提示信息 |

失败的文件不会中断整个批次，可以在日志里逐条查看原因。

---

## 5 用法二：拖放转换（最省事）

1. 选中一个或多个 Office 文件（也可以直接选一个文件夹）；
2. 拖到 `拖放文件转换.bat` 图标上松手；
3. 弹出的黑色窗口会显示转换进度，转换完成后按任意键关闭。

结果 `.md` 输出到**源文件所在目录**。若要指定输出目录，请改用图形界面。

---

## 6 用法三：命令行（批量 / 脚本化）

在程序目录打开 PowerShell 或 CMD：

```bat
:: 转换单个文件（输出到源文件同目录）
office2md-cli.exe 报告.docx

:: 转换整个目录到指定输出目录
office2md-cli.exe D:\资料 -o D:\out

:: 多个目标
office2md-cli.exe a.docx b.xlsx c.pptx -o out

:: 不包含 PPT 备注、包含隐藏工作表
office2md-cli.exe D:\资料 -o out --no-notes --hidden-sheets

:: 不覆盖已有 md
office2md-cli.exe D:\资料 -o out --no-overwrite

:: 查看参数说明
office2md-cli.exe --help
```

退出码：`0` 全部成功；`1` 有文件失败；`2` 参数或路径错误。可直接用于批处理判断。

## 7 转换结果说明

### 7.1 输出文件构成

```
源文件：  报告.docx
输出：    报告.md
          报告_files\
              image001.png
              image002.emf
```

md 中以相对路径引用图片（`![](报告_files/image001.png)`），因此**移动 md 时请连同 `_files` 目录一起移动**。

### 7.2 Word 转换规则

| Word 内容 | 转换结果 |
| --- | --- |
| 标题 1/2/3… | `#` / `##` / `###`… |
| 正文 | 普通段落 |
| 粗体、斜体、删除线 | `**粗体**`、`*斜体*`、`~~删除~~` |
| 项目符号、编号列表 | `-` 列表、`1.` 列表（保留缩进层级） |
| 表格 | Markdown 表格，首行作为表头 |
| 图片 | 导出到 `_files` 目录并插入引用 |
| 超链接 | `[文字](链接)` |
| 页眉页脚、脚注、批注 | 不输出 |

### 7.3 Excel 转换规则

- 每个工作表输出为一个 `## 工作表名` 章节 + 一张表格；
- 合并单元格只在左上角保留内容；
- 公式取 Excel 保存时的计算结果；如果该文件从未被 Excel 保存过，公式会变成空值或公式原文，日志里会提示「建议用 Excel 打开并保存一次」；
- 日期输出为 `YYYY-MM-DD` 格式；
- 隐藏工作表默认不输出；
- 空行空列会自动去掉。

### 7.4 PowerPoint 转换规则

- 每张幻灯片输出为 `## 序号. 标题`；
- 文本框内容按层级转成段落或缩进列表；
- 表格转 Markdown 表格；图表按「类别 + 各系列数值」还原成表格；
- 图片单独导出；
- 演讲者备注放在该页末尾的 `> **备注**` 引用块里。

## 8 常见问题

| 现象 | 原因 | 处理办法 |
| --- | --- | --- |
| 双击 exe 没反应 | 杀毒软件拦截了未签名程序 | 加入白名单，或用 `启动转换工具.bat` 启动并查看日志 |
| 提示「未检测到 Microsoft Word，无法转换老格式」 | 目标机没装 Office | 安装 Office，或在别的机器上把 .doc 另存为 .docx 再转 |
| 提示「文件被占用或无权限」 | 文件正在 Office 中打开，或目录只读 | 关闭该文件；把文件复制到本地目录再转 |
| 转换成功但 md 是空的 | 文档只有图片/扫描件，没有文字 | 本工具不做 OCR，需要先做文字识别 |
| 表格在 md 里对不齐 | 原表格有大量合并单元格 | Markdown 表格不支持合并单元格，属格式限制 |
| 公式变成灰色代码块 | 公式仅提取纯文本，不做 LaTeX 转换 | 见设计书限制 L1 |
| Excel 数字变成空 | 公式没有缓存值 | 用 Excel 打开该文件并保存一次，再转换 |
| 中文乱码（控制台） | 控制台代码页不是 UTF-8 | 程序已自动设置；若仍乱码，先在窗口执行 `chcp 65001` |
| 输出目录里没有图片 | 文档本身没有内嵌图片 | 正常现象 |
| 转换很慢 | 老格式要走 Office 另存，每个文件 3–6 秒 | 属正常；可先把老格式批量另存为新格式 |

日志文件位置：`logs\office2md_日期.log`（与 exe 同级目录），排错时请提供该文件。

## 9 开发机上如何重新构建（维护人员阅读）

> 普通使用者可以跳过本节。

### 9.1 前置：安装 Python

1. 安装 **Python 3.13 x64**（安装时勾选 `Add python.exe to PATH`）；
2. 打开 PowerShell，确认：

```bat
python --version
```

### 9.2 安装依赖（完全离线）

项目目录内已随包保存所有依赖 wheel：

```bat
cd /d <项目根目录>
python -m pip install --no-index --find-links=vendor\wheels -r requirements.txt -r requirements-build.txt
```

`--no-index` 保证不访问网络，全部从 `vendor\wheels` 安装。

如需要新增依赖，先在联网机器上执行：

```bat
python -m pip download -r requirements.txt -d vendor\wheels --only-binary=:all: --platform win_amd64 --python-version 3.13 --implementation cp
```

并把新文件登记到 `vendor\CHECKSUMS.txt`。

### 9.3 源码运行（调试）

```bat
python app.py                     :: 图形界面
python app.py samples -o out_test :: 命令行
```

### 9.4 一键打包

```bat
build\build_exe.bat
```

脚本会依次完成：离线装依赖 → PyInstaller 打包 → 组装发行目录与 zip。

产物：

```
dist\office2md\                         PyInstaller 原始输出
dist\office2md-1.0.0-win64\             发行目录（可直接拷走）
dist\office2md-1.0.0-win64.zip          发行压缩包
```

### 9.5 回归测试

```bat
python tools\make_samples.py samples
python tools\make_legacy_samples.py        :: 需本机装 Office
python app.py samples -o out_test
python app.py samples_legacy -o out_legacy
```

## 10 卸载与清理

- 本程序不写注册表、不装服务、不写系统目录；
- 卸载 = 直接删除整个程序文件夹；
- 运行过程中产生的 `logs\`、`temp\` 目录会随程序目录一起删除；
- 转换结果（`.md` 与 `_files` 目录）在源文件旁边或你指定的输出目录，需自行清理。

## 12 两种发行包怎么选

项目会产出两个发行目录，**按需选一个拷到目标机即可**，不要混用。

### 12.1 `office2md-1.0.0-win64`（exe 版，推荐）

| 项 | 说明 |
| --- | --- |
| 构成 | `office2md.exe` / `office2md-cli.exe` / `_internal` |
| 体积 | 约 65 MB |
| 是否需要 Python | 不需要 |
| 适合谁 | 只想用工具、不关心源码的使用者 |
| 启动 | 双击 `office2md.exe` 或 `启动转换工具.bat` |

### 12.2 `office2md-1.0.0-src-portable`（源码便携版）

| 项 | 说明 |
| --- | --- |
| 构成 | `app.py` + `src\` + `runtime\`（Python 3.13 嵌入式 + 离线依赖） |
| 体积 | 约 85 MB |
| 是否需要 Python | 不需要（自带 `runtime\python.exe`） |
| 适合谁 | 需要看源码、改功能、加格式的维护人员 |
| 启动 | 双击 `启动转换工具.bat`（脚本会自动使用 `runtime\python.exe`） |
| 修改代码 | 直接改 `src\office2md\*.py`，重新双击 bat 即生效 |

### 12.3 两者的关系

- 功能完全一致，代码同源；
- exe 版启动更快、目录更干净；
- 源码便携版改完即生效，但首次启动稍慢；
- 源码便携版也可以在装了 Python 的开发机上直接用系统 Python 运行（bat 会自动优先用 `runtime\python.exe`）。

### 12.4 交付建议

- release 包 `office2md-1.0.0.zip` 已把两版放在同一个 `office2md-1.0.0\` 目录下，并附 `选择说明.txt`，解压即可按说明选；
- 普通办公用户 → 只发 `office2md-1.0.0-win64\` 子目录也够用；
- 需要长期维护、可能要改规则的人 → 发整个包，用 `src-portable` 版；
- 两版各占独立目录，不会混淆 `_internal` 与 `runtime`。
