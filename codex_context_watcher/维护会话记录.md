## 已确定的实现

- 数据源不是 `threads.tokens_used` 累计值，而是每个 rollout JSONL 中的 `token_count` 事件。
- 每个 thread 独立读取 `last_token_usage.input_tokens` 和 `model_context_window`。
- 监控范围包括 Codex CLI 和 VS Code Codex 插件会话。
- 预警方式是 Windows 无边框弹窗；点击后尝试聚焦 CLI 宿主窗口或 VS Code 窗口。
- 同一 thread 的同一预警档位只提醒一次，低占用回落后允许重新提醒。
- 当前阈值：
  - `258k`：使用量达到 `185k` 时建议 `codexr512`，达到 `210k` 时强烈建议 `codexr512`。
  - `512k`：使用量达到 `370k` 时建议 `codexr1m`，达到 `415k` 时强烈建议 `codexr1m`。
  - `1m`：使用量达到 `720k` 或 `810k` 时建议阶段总结后新开线程。
